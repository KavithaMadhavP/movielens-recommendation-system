# 🎬 MovieLens Recommendation System

A **User-Based Collaborative Filtering** recommendation system built using the **MovieLens dataset** and deployed with **Streamlit**.

## 🚀 Features
- User-based collaborative filtering
- Cosine similarity for user similarity
- Cold-start support (new user ratings)
- Interactive Streamlit UI
- Real-world MovieLens dataset

## 📊 Dataset
- Source: MovieLens (ml-latest-small)
- Ratings: userId, movieId, rating

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
